GEO Getter

Save public GEO / ENA raw FASTQ files and GEO supplementary or processed files into a local accession folder.

Latest release Repository

What GEO Getter saves

  • Raw FASTQ files resolved through ENA for public SRA / ENA records.
  • GEO supplementary and processed files listed on public GEO records.
  • Manifest and download log TSV files that record URLs, expected sizes, checksums when available, and local paths.

Install

Download GEOGetter from the latest GitHub Release.

  • Choose the .exe installer for normal use, then start GEOGetter from the Start menu.
  • Choose the win-x64-portable.zip package when you do not want installation; extract it and run start_geo_getter.vbs.
  • Requirements: Windows 10 / 11 64-bit, internet access, and enough free disk space for the selected files.
  • The installer is unsigned, so Windows SmartScreen may show a warning.

Quick start

  1. Start GEOGetter.
  2. Paste an accession or GEO page URL.
  3. Select Find files.
  4. Select the raw FASTQ files and/or GEO supplementary or processed files to save.
  5. Confirm the save folder. The default base folder is Downloads\GEOGetter.
  6. Select Download selected files.

Accepted input

Input Examples
GEO accession GSE52778, GSM...
GEO page URL https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE52778
Sequence archive accession SRP..., SRX..., SRR..., SRS..., ERP..., ERX..., ERR..., ERS..., DRP..., DRX..., DRR..., DRS...
BioProject accession PRJNA..., PRJEB..., PRJDB...
BioSample accession SAMN..., SAMEA..., SAMD...

Output folder

GEO Getter writes selected files and TSV records under the accession folder shown by the app. 

Downloads/GEOGetter/
  GSE52778/
    GSE52778_fastq_manifest.tsv
    GSE52778_supplementary_manifest.tsv
    GSE52778_download_log.tsv
    SRR1039508_1.fastq.gz
  • *_fastq_manifest.tsv: FASTQ URL, ENA expected MD5, expected size, and local path.
  • *_supplementary_manifest.tsv: GEO supplementary or processed file URL and local path.
  • *_download_log.tsv: download status for each selected file.
  • verification_report.tsv: optional report when saved FASTQ files are checked later.

Checks and resume

  • FASTQ downloads are checked against MD5 values when ENA provides expected MD5 values.
  • GEO supplementary and processed files are saved from GEO URLs and are not verified with ENA FASTQ MD5 values.
  • To resume an interrupted FASTQ download, choose the same save folder. Incomplete files remain as .part files.
