GEO Getter

public GEO / ENA data から raw FASTQ と GEO supplementary / processed file を accession folder に保存します。

最新版 Repository

保存できるもの

  • public SRA / ENA record から解決した raw FASTQ files。
  • public GEO record に掲載された GEO supplementary / processed files。
  • URL、expected size、checksum がある場合の expected MD5、local path を記録する manifest / download log TSV。

インストール

GEOGetter は latest GitHub Release からダウンロードします。

  • 通常は .exe installer を選び、インストール後に Start menu の GEOGetter から起動します。
  • インストールせずに使う場合は win-x64-portable.zip package を展開し、start_geo_getter.vbs を実行します。
  • 必要な環境: Windows 10 / 11 64-bit、internet access、保存する files に足りる disk space。
  • installer は unsigned のため、Windows SmartScreen の警告が表示される場合があります。

Quick start

  1. GEOGetter を起動します。
  2. accession または GEO page URL を貼り付けます。
  3. ファイルを検索 を押します。
  4. 保存する raw FASTQ files と GEO supplementary / processed files を選びます。
  5. 保存先を確認します。既定の base folder は Downloads\GEOGetter です。
  6. 選択ファイルをダウンロード を押します。

入力

種類 例
GEO accession GSE52778, GSM...
GEO page URL https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE52778
Sequence archive accession SRP..., SRX..., SRR..., SRS..., ERP..., ERX..., ERR..., ERS..., DRP..., DRX..., DRR..., DRS...
BioProject accession PRJNA..., PRJEB..., PRJDB...
BioSample accession SAMN..., SAMEA..., SAMD...

保存先

GEO Getter は、app に表示された accession folder の下に selected files と TSV records を保存します。 

Downloads/GEOGetter/
  GSE52778/
    GSE52778_fastq_manifest.tsv
    GSE52778_supplementary_manifest.tsv
    GSE52778_download_log.tsv
    SRR1039508_1.fastq.gz
  • *_fastq_manifest.tsv: FASTQ URL、ENA expected MD5、expected size、local path。
  • *_supplementary_manifest.tsv: GEO supplementary / processed file URL と local path。
  • *_download_log.tsv: selected file ごとの download status。
  • verification_report.tsv: 保存済み FASTQ を後で確認した場合の optional report。

チェックと再開

  • FASTQ downloads は、ENA が expected MD5 を返す場合に MD5 を照合します。
  • GEO supplementary / processed files は GEO URL から保存し、ENA FASTQ MD5 では照合しません。
  • 中断した FASTQ download を再開するには、同じ保存先 folder を選びます。途中までの file は .part として残ります。
