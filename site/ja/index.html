Windows x64 desktop app

GEO Getter

public GEO / ENA data から raw FASTQ と GEO supplementary / processed files を保存する Windows 向けデスクトップアプリです。

GitHub Releases からダウンロード Repository を開く

配布物は GitHub Releases にあります。installer は GEOGetter-Setup-vX.Y.Z.exe、portable zip は GEOGetter-vX.Y.Z-win-x64-portable.zip という名前です。

installer について

Windows installer は未署名のため、Windows SmartScreen の警告が出る 場合があります。この repository の latest GitHub Release から download してください。

対応 input

app の input 欄に accession または GEO page URL を 1 つ貼り付けます。

  • GEO accession: GSE52778, GSM...
  • GEO page: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE52778
  • SRA / ENA accession: SRP..., SRX..., SRR..., ERP..., ERR...
  • BioProject accession: PRJNA..., PRJEB..., PRJDB...
  • BioSample accession: SAMN..., SAMEA..., SAMD...

基本的な使い方

install した app の名前は GEOGetter です。portable zip では start_geo_getter.vbs を実行します。

  1. GEOGetter を起動します。
  2. accession または GEO page URL を貼り付けます。
  3. Find files を選択します。
  4. 保存する raw FASTQ または GEO supplementary / processed files を選びます。
  5. 保存先を確認します。既定の base folder は Downloads\GEOGetter です。
  6. Download selected files を選択します。

保存されるもの

GEO Getter は app に表示された accession folder の下に、選択した files と TSV records を保存します。

  • *_fastq_manifest.tsv: FASTQ URL、ENA expected MD5、expected size、local path。
  • *_supplementary_manifest.tsv: GEO supplementary / processed file URL と local path。
  • *_download_log.tsv: 選択した file ごとの download status。
  • verification_report.tsv: 保存済み FASTQ をあとで確認した場合の optional report。

完全性確認

FASTQ は、ENA が expected MD5 を返す場合に MD5 を照合します。GEO supplementary / processed files は GEO URL から保存し、ENA FASTQ MD5 では照合しません。
